# 거북목 AI 스트레칭 코치 웹앱

거북목과 라운드숄더 증상을 완화하기 위한 AI 기반 스트레칭 코치입니다.

## 🚀 시작하기

### 설치
```bash
npm install
```

### 실행
```bash
npm start
```

앱이 [http://localhost:3000](http://localhost:3000)에서 열립니다.

## 📦 빌드
```bash
npm run build
```

프로덕션 빌드가 `build` 폴더에 생성됩니다.

## ✨ 기능

- 🤖 거북목 관련 증상 자동 감지
- 💪 맞춤형 스트레칭 루틴 추천
- ⏱️ 시간대별 루틴 선택 (기본/짧은 루틴)
- ⚠️ 위험 신호 감지 시 전문가 상담 권장
- 📱 모바일 반응형 디자인

## 🎯 MVP 포함 기능

- 거북목 관련 증상 키워드 감지
- 기본 루틴 / 짧은 루틴 자동 추천
- 저림, 마비, 어지러움 등 위험 신호 감지
- 대화형 입력과 추천 루틴 카드 표시
